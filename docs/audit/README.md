## 2. Top 13 Critical Findings (Immediate Action Recommended)

1. **[NAT-C01] Tier-1 `PServerBootstrapper` Spawns `megingiard_privd` as `uid=0 (root)` Instead of `uid=2000 (shell)` ([PServerBootstrapper.kt](file:///Users/maikthomalla/.gemini/antigravity/worktrees/Megingiard/check_current_time/companion/domain/src/main/java/com/stormpanda/megingiard/privd/PServerBootstrapper.kt#L170-L194))**
   - `PServiceBridge` executes as `root`. Running `chown 2000:2000` on the binary does not drop process UID on execution. If Tier-1 later fails or keys rotate, Tier-2 ADB (`uid=2000`) cannot `kill -9` the root daemon (`EPERM`), permanently locking port `51234` until reboot. Also discards `R`/`N`/`E` startup readiness tokens via `>/dev/null 2>&1 &`.
2. **[GPM-C01] Premature ADB Credential Persistence Poisons `hasCredentials()` (`isDevicePaired`) Before Pairing Succeeds ([PrivdAdbConnectionManager.kt](file:///Users/maikthomalla/.gemini/antigravity/worktrees/Megingiard/check_current_time/companion/domain/src/main/java/com/stormpanda/megingiard/privd/PrivdAdbConnectionManager.kt#L72-L203), [PrivdBootstrapper.kt](file:///Users/maikthomalla/.gemini/antigravity/worktrees/Megingiard/check_current_time/companion/domain/src/main/java/com/stormpanda/megingiard/privd/PrivdBootstrapper.kt#L147-L206))**
   - `PrivdAdbConnectionManager.getInstance()` writes `privd_adb_key.bin` (unencrypted raw PKCS#8 private key) and `privd_adb_cert.bin` to `noBackupFilesDir` inside `init` *before* `mgr.pair()` is called. Any failed or cancelled pairing attempt permanently sets `hasCredentials() == true`, causing Auto-Setup to skip pairing and enter an unrecoverable `ADB_PAIRING_REQUIRED` loop.
3. **[A11Y-C01] First-Run `OnboardingWizardDialog` Permanently Locks Out Users on Unsupported System Locales or Non-Wi-Fi `privd` Setups ([OnboardingWizardDialog.kt](file:///Users/maikthomalla/.gemini/antigravity/worktrees/Megingiard/check_current_time/companion/ui/src/main/java/com/stormpanda/megingiard/ui/onboarding/OnboardingWizardDialog.kt#L431-L450))**
   - When the system locale is not `en`, `de`, or `zh-TW`/`zh-HK`, `PrivilegedStepContent` hides the Auto-Setup button and instructs the user to *"1. Skip this step for now by proceeding to the next step"*, but `isNextEnabled` for `OnboardingStepId.PRIVILEGED` does not check `!isLanguageSupported` (and requires `isWifiActive && isDevModeActive && isWirelessActive && isDevicePaired && privdState == PrivdState.RUNNING`), permanently disabling "Next" and locking non-root users out of entering the app.
4. **[MIR-C04] Unbounded Frame Accumulation (`OutOfMemoryError`), Main-Thread Pixel Analysis & Disk I/O, and Mid-Calibration Dimension Mismatch in `VisualAutoTuneCoordinator` ([VisualAutoTuneCoordinator.kt](file:///Users/maikthomalla/.gemini/antigravity/worktrees/Megingiard/check_current_time/companion/ui/src/main/java/com/stormpanda/megingiard/mirror/VisualAutoTuneCoordinator.kt#L177-L556), [CutoutAutoTuner.kt](file:///Users/maikthomalla/.gemini/antigravity/worktrees/Megingiard/check_current_time/companion/domain/src/main/java/com/stormpanda/megingiard/mirror/CutoutAutoTuner.kt#L95-L150))**
   - Accumulates raw `IntArray(cropW * cropH)` frames in `sampledFrames = ArrayList<IntArray>()` at `8.33 Hz` for up to `180s` (`1,500` frames; `8.29 MB/frame` at `1920x1080`, exhausting over `800 MB` in 12 seconds), runs full-frame `Bitmap` allocation, `getPixels`, pixel variance loops, and PNG disk writes on `Dispatchers.Main`, and throws `ArrayIndexOutOfBoundsException` if `cropW`/`cropH` changes mid-calibration.
5. **[NAT-C02] `MegingiardSettingsProvider` Exposes `steamGridDbApiToken` in Plaintext to Any Installed App ([MegingiardSettingsProvider.kt](file:///Users/maikthomalla/.gemini/antigravity/worktrees/Megingiard/check_current_time/companion/ui/src/main/java/com/stormpanda/megingiard/provider/MegingiardSettingsProvider.kt#L89-L107))**
   - Exported `ContentProvider` with no `readPermission` or `Binder.getCallingUid()` check returns `SettingsManager.steamGridDbApiToken.value` on `/settings`.
6. **[NAT-C03] Unauthenticated `DirectMirrorServer` Allows Any Local Process to Hijack Display 0 Capture ([DirectMirrorServer.java](file:///Users/maikthomalla/.gemini/antigravity/worktrees/Megingiard/check_current_time/mirrorserver/src/main/java/com/stormpanda/megingiard/mirrorserver/DirectMirrorServer.java#L116-L195))**

7. **[NAT-C04] Stuck Hardware Touchscreen Slots (`/dev/input/event6`), Mouse Buttons, and Gamepad Inputs on Disconnect ([megingiard_privd.c](file:///Users/maikthomalla/.gemini/antigravity/worktrees/Megingiard/check_current_time/companion/ui/src/main/cpp/megingiard_privd.c#L1104-L1297), [cmd_parsers.h](file:///Users/maikthomalla/.gemini/antigravity/worktrees/Megingiard/check_current_time/companion/ui/src/main/cpp/cmd_parsers.h#L16))**

  - `MIR-H07`: `CutoutMaskManager` calls `.recycle()` on cached bitmaps in `saveMask`/`deleteMask` while `MultiCutoutContainer` still holds and draws them, and performs synchronous disk I/O + BFS flood-fill during composition.

## 4. Prioritized Remediation Roadmap

1. **Phase 1 — Security, Privileged Bootstrap & Native Daemon Stability (`03`, `12`, `13`, `14`):**
   - Fix UID drop (`2000:2000`) and readiness token parsing in `PServerBootstrapper` (`NAT-C01`), defer/encrypt ADB credential persistence in `PrivdAdbConnectionManager` until SPAKE2+ pairing succeeds (`GPM-C01`), unblock `OnboardingWizardDialog` on unsupported locales / non-Wi-Fi setups (`A11Y-C01`), and fix `findAndToggleSwitch` / `findAndClickAllowDialogButton` in `MegingiardAccessibilityService` (`A11Y-H01`, `A11Y-H02`).
   - Move `SignatureGuard.verify(this)` to the top of `MainActivity.onCreate()` (`GPM-H02`), and add caller UID / signature verification in `MegingiardSettingsProvider` (`NAT-C02`, `NAT-H09`) and `DirectMirrorServer` (`NAT-C03`).
   - Release active touch slots (`active_slots_mask`), mouse buttons, and gamepad state on disconnect in `megingiard_privd.c` / `cmd_parsers.h` (`NAT-C04`, `NAT-H03`), add `O_CLOEXEC` / `SOCK_CLOEXEC` (`NAT-H01`), and fix `sigaction` + `PR_SET_PDEATHSIG` (`NAT-H02`).
2. **Phase 2 — Input, Gamepad Navigation & Mirror Correctness (`04`, `06`, `13`, `14`, `15`):**
   - Fix `KeyRepeatController.onKeyMove` (`prevDef.isCharacterKey`) and `onCancel`/`dispose()` key release (`INP-C01`, `INP-C02`), `detectHoldPointerEvents` `finally` release (`UI-M02`), plus `"altgr"` key ID in `KeyboardScreen.kt` (`CUI-H01`).
   - Fix `GamepadTwoPaneScaffold` sub-page focus recovery (`GPM-H03`), `primaryOverlayFocusable` `KeyUp` pairing (`GPM-H04`), `GamepadSliderCard` `itemKey` (`GPM-M02`), and Tier-2 `BackHandler` cancel semantics (`GPM-M03`).
   - Replace unbounded `sampledFrames` accumulation in `VisualAutoTuneCoordinator` with incremental `O(pixelCount)` stats on `Dispatchers.Default` (`MIR-C04`), fix cancellation `finally` races (`MIR-H09`), and stop recycling live preview `StateFlow` bitmaps (`MIR-H10`).
   - Fix `GpuMotionSmoother` `glGenTextures` (`MIR-C01`), vertical coordinate inversion (`MIR-H01`), and `setFrozen` thread ordering (`MIR-H02`).
   - Stop tearing down `DirectPrivdMirrorSession` on `isFrozen` (`MIR-H03`), fix `Bitmap.recycle()` races (`MIR-C02`, `MIR-C03`, `MIR-H04`, `MIR-H07`), replace `updateLayout` with `updateLayoutLive` in `CropSelectorOverlay` (`MIR-H08`), fix single-cutout/circle blending (`MIR-H05`) and Z-order hit-testing (`INP-H01`), and fix `ScreenshotTarget.TOP`/`BOTH` Scoped Storage handling (`GPM-H01`).
3. **Phase 3 — State Persistence, Media Lifecycle & Config Hardening (`02`, `05`, `07`, `08`, `13`):**
   - Enforce `AGENTS.md §7.6` Load-Once Guards in `MacroPadSettings`, `InstalledAppsManager`, `RomManager`, and `GameFocusPairManager`.
   - Bound ZIP entry decompression and enforce `targetDir` canonical path containment in `ConfigManager` (`DOM-C01`, `DOM-H01`), export/import `cutout_masks/` (`DOM-H06`), and clear `pendingInAppImportMode` in `GlobalSettingsScreen` (`CUI-H06`).
